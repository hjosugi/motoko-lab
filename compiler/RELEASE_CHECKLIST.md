# Release Checklist Study

upstream `Building.md`を毎回確認します。

- latest master
- compiler/runtime/docs build clean
- changelog heading exact format
- release PR title/version consistency
- CI green
- release artifact verification
- `motoko-core` tag/update
- downstream: npm package, package set, VS Code, ICP Ninja/SDK docs
- soak period and risk decision

実際のrelease権限はmaintainer policyに従います。
