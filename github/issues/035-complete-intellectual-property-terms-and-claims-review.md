# Context

Marketing a provenance service can create legal risk if it promises authorship or copyright certainty.

## Scope

- [ ] Review product wording, terms, privacy, dispute, takedown, AI disclosure, and marketplace licenses.
- [ ] Define supported jurisdictions and customer responsibilities.
- [ ] Separate technical evidence from legal conclusions.
- [ ] Review immutable-data implications.
- [ ] Create escalation process.

## Acceptance criteria

- [ ] UI never says blockchain guarantees copyright.
- [ ] Terms explain false claims and revocation.
- [ ] Marketplace terms hash/version is preserved.
- [ ] Legal review date and owner are recorded.

## Test plan

- [ ] Minor users
- [ ] Agency work-for-hire
- [ ] Cross-border dispute
- [ ] AI provider terms
