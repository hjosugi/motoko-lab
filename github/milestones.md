# Milestones

Create these exact milestone titles before applying issue drafts:

- `M0 Compile Baseline`: compiler, Candid, and integration-test baseline
- `M1 Protocol Core`: provenance protocol and verifier foundations
- `M2 Production Safety`: upgrade, privacy, audit, recovery, and operations gates
- `M3 Payments and Business`: payments, billing, metering, and unit economics
- `M4 Scale and Interop`: sharding, standards bridges, frontend, and governance readiness
- `M5 Upstream Maintainer`: sustained Motoko compiler, core, and ecosystem contribution

Create milestones manually or through trusted GitHub automation. The included issue loader passes a milestone title only when `USE_MILESTONES=1`.
