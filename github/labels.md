# Labels

The issue drafts use the following exact GitHub label names.

## Priority

- `priority:P0`: launch, security, or data-loss blocker
- `priority:P1`: important product or scale work
- `priority:P2`: valuable but not blocking

## Type

- `type:security`
- `type:feature`
- `type:research`
- `type:docs`
- `type:chore`

## Effort

- `effort:S`
- `effort:M`
- `effort:L`
- `effort:XL`
